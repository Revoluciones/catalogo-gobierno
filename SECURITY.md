# Seguridad y datos personales

Si encuentras datos personales en el repositorio (en una ficha, un reporte o en `fuentes-crudas.tar.gz`), una credencial, o un problema de seguridad en las herramientas, **no abras un issue público**.

Avísanos en privado desde la pestaña **Security → Report a vulnerability** de este repositorio. Solo el equipo de mantenimiento lo ve.

Quitamos los datos personales del repositorio en cuanto confirmamos el aviso, incluido el historial cuando hace falta.
