# Código de conducta

Aquí colabora gente de todo México y de cualquier postura política. Para que eso funcione:

- Trata a las demás personas con respeto, aunque no estés de acuerdo.
- Discute las ideas y las fuentes, no a las personas.
- Nada de insultos, acoso, amenazas ni ataques por origen, género, religión, discapacidad, orientación o postura política.
- Nada de propaganda: este es un catálogo neutral, no un espacio de campaña.
- No publiques datos personales de nadie.

Adoptamos el [Contributor Covenant 2.1](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/). Para reportar una conducta, usa el aviso privado que explica [SECURITY.md](SECURITY.md). El equipo de Revoluciones revisa cada reporte y puede ocultar comentarios o bloquear cuentas.
